# PneumoScan

Explainable AI for pneumonia detection from pediatric chest X-rays. PneumoScan classifies an X-ray as NORMAL or PNEUMONIA, shows a Grad-CAM heatmap of the regions that influenced the prediction, and uses the Anthropic Claude API to write a short plain-language explanation.

> **Disclaimer:** This is an academic project (DSC550). It is not a medical device and must not be used for clinical diagnosis. All results need review by a qualified clinician.

## Features

- Three models: a custom CNN, ResNet50 and MobileNetV2 (the last two use ImageNet transfer learning)
- Grad-CAM heatmaps with an adjustable overlay slider
- Plain-language explanations generated by Claude, with a template fallback if the API is unavailable
- A "Compare all models" view showing predictions, confidence and inference time side by side
- An evaluation tab with test-set metrics (accuracy, precision, recall, specificity, F1, ROC-AUC, confusion matrix)

## Dataset

Kermany et al. (2018), *Labeled Optical Coherence Tomography (OCT) and Chest X-Ray Images for Classification*, Mendeley Data, DOI: 10.17632/rscbjbr9sj.2. It contains 5,856 pediatric chest X-rays (NORMAL and PNEUMONIA).

The dataset is not included in this repository. Download it and place it in `backend/data/` so that it contains `train/` and `test/` folders, each with `NORMAL/` and `PNEUMONIA/` subfolders.

## Setup

### Prerequisites

- Python 3.11
- Node.js 18+ and npm
- An Anthropic API key (optional; without it the app falls back to a template explanation)

### 1. Clone

```bash
git clone https://github.com/J2001frey/PneumoScan.git
cd PneumoScan
```

### 2. Backend

```bash
python3 -m venv pytorch_env
source pytorch_env/bin/activate
pip install -r backend/requirements.txt
cp backend/.env.example backend/.env
```

Open `backend/.env` and set your key:

```
ANTHROPIC_API_KEY=your_key_here
```

Trained weights are not stored in this repository because of file size. Place the checkpoints in `backend/saved_models/` using these names:

- `mobilenetv2_weighted_ce.pt` (default model)
- `resnet50_weighted_ce.pt`
- `custom_cnn_weighted_ce.pt`

Alternatively, train them yourself (see Training below).

Start the API:

```bash
cd backend
uvicorn app.main:app --reload --port 8000
```

Interactive API docs: http://localhost:8000/docs

### 3. Frontend

In a second terminal:

```bash
cd frontend
npm install
npx ng serve
```

Open http://localhost:4200. The frontend expects the API at http://localhost:8000 (set in `frontend/src/environments/`).

## Training

The custom CNN and ResNet50 were trained on Google Colab (`backend/notebooks/pneumoscan_colab_both_models.ipynb`); MobileNetV2 was trained locally.

- Optimizer: Adam (lr 1e-3 for the custom CNN, 1e-4 for the pretrained models) with cosine annealing
- Loss: class-weighted cross-entropy
- Validation split: 85/15 stratified, seed 42
- Early stopping on validation macro-F1 (patience 4)

To train and evaluate locally from `backend/`:

```bash
python train.py --model mobilenetv2 --loss weighted_ce --epochs 15
python evaluate.py --model_file mobilenetv2_weighted_ce.pt
```

`--model` accepts `custom_cnn`, `resnet50` or `mobilenetv2`.

## Limitations

- Trained on a single pediatric dataset from one center; it may not generalize to other populations or imaging equipment.
- All models produce false alarms on NORMAL images (test specificity 0.49 to 0.82).
- A fixed 0.5 decision threshold is used.
- Agreement between models and high confidence are not proof of correctness.
