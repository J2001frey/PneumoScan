# PneumoScan

Explainable AI for pneumonia detection from pediatric chest X-rays. PneumoScan classifies an X-ray as NORMAL or PNEUMONIA, shows a Grad-CAM heatmap of the regions that influenced the prediction, and uses the Anthropic Claude API to write a short plain-language explanation.

> **Disclaimer:** This is an academic project (DSC550). It is not a medical device and must not be used for clinical diagnosis. All results need review by a qualified clinician.

## Features

- Three models: a custom CNN, ResNet50 and MobileNetV2 (the last two use ImageNet transfer learning)
- Grad-CAM heatmaps with an adjustable overlay slider
- Plain-language explanations generated by Claude, with a template fallback if the API is unavailable
- A "Compare all models" view that shows predictions, confidence and inference time side by side
- An evaluation tab with test-set metrics (accuracy, precision, recall, specificity, F1, ROC-AUC, confusion matrix)

## Dataset

Kermany et al. (2018), *Labeled Optical Coherence Tomography (OCT) and Chest X-Ray Images for Classification*, Mendeley Data, DOI: 10.17632/rscbjbr9sj.2. It has 5,856 pediatric chest X-rays (NORMAL and PNEUMONIA). The dataset is not included in this repository. Download it and place it in `backend/data/` so that it has `train/` and `test/` folders, each with `NORMAL/` and `PNEUMONIA/` subfolders.

## Setup

### Prerequisites

- Python 3.11
- Node.js 18+ and npm
- An Anthropic API key (optional; without it the app uses a template explanation)

### 1. Clone

```bash
git clone https://github.com/J2001frey/PneumoScan.git
cd PneumoScan
```

### 2. Backend

```bash
python3 -m venv pytorch_env
source pytorch_env/bin/activate
pip install -r backend/requirements.txt
cp backend/.env.example backend/.env
```

Open `backend/.env` and set your key:

```
ANTHROPIC_API_KEY=your_key_here
```

Place the trained weights (`.pt` files) in `backend/saved_models/`. They are not stored in this repository because of file size. <!-- verify: add your Drive link here -->

Start the API:

```bash
cd backend
uvicorn app.main:app --reload --port 8000   # verify the module path
```

The API docs are at http://localhost:8000/docs.

### 3. Frontend

```bash
cd frontend
npm install
npx ng serve
```

Open http://localhost:4200.

## Training

Training and evaluation scripts are in `backend/`. The custom CNN and ResNet50 were trained on Google Colab (see `notebooks/`); MobileNetV2 was trained locally.

- Optimizer: Adam (lr 1e-3 for the custom CNN, 1e-4 for the pretrained models), cosine annealing
- Loss: class-weighted cross-entropy
- Validation split: 85/15 stratified, seed 42
- Early stopping on validation macro-F1 (patience 4)

```bash
python train.py --model mobilenetv2   # verify the arguments
python evaluate.py --model mobilenetv2
```

## Limitations

- Trained on one pediatric dataset from a single center; it may not generalize to other populations or imaging equipment.
- On the test set, all models produce false alarms on NORMAL images (specificity 0.49 to 0.82).
- A fixed 0.5 decision threshold is used.
- Model agreement and high confidence are not proof of correctness.
